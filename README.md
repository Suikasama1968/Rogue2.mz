# Rogue Clone II for MZ-1500 (Subset)

本プログラムは、MZ-1500向けに移植した「ローグ・クローン2」のサブセット版です。

## 移植元

移植元は、Timothy Stoehrによる`Rogue-clone: Version II`から派生した
`rogueclone2s 6.0`の日本語UTF-8版です。

画面表示、キーボード、I/O、文字コード、簡易cursesなど、MZ固有の処理は
原則として`mz_`で始まるファイルへ分離しています。それ以外のファイル名、関数名、
定数、処理順は、可能な範囲で移植元に合わせています。

## 機能制限

本移植版では、主にMZ-1500の仕様に依存し次の機能が未実装、または簡略化されています。

- セーブおよびリストア
- 得点ランキングの保存と表示
- コマンドラインオプション、環境変数、プレイヤー名の設定
- ヘルプ、バージョン表示、ウィザードモード
- メッセージ履歴と過去メッセージの再表示
- アイテムへの名前付け、識別、呼び名の設定
- 巻物の識別処理、および一部の巻物の効果
- 薬の一部が未実装
- 杖の一部が未実装
- 腕力増加以外の指輪の効果
- モンスターの特殊攻撃の一部
- モンスターの日本語名称をオリジナルから変更
- 長距離移動、連続コマンド、回数指定など一部の標準コマンド
　
## 主な操作

標準的なRogueの仕様に従います。キーボードのデフォルトは小文字になっているので、大文字を入力する場合はシフトキーを押してください。

## ビルド

Cygwin、z88dk、GNU Make、Python 3を使用します。

```sh
cd src
make
```

`mz_mesg`はビルド時にMZ-1500の文字コードへ変換され、`ROGUE_MESG.mzt`になります。
プログラムの`ROGUE_OBJ.mzt`とメッセージの`ROGUE_MESG.mzt`をこの順に連結した
`ROGUE.mzt`が、QuickDisk用の実行ファイルです。
